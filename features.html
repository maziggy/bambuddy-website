Virtual Printer Proxy Mode

Print from anywhere in the world. Control your Bambu Lab printer remotely without Bambu Cloud, port forwarding, or VPN.

How it works: Configure Proxy Mode in Settings → Virtual Printer. Add your Bambuddy server as a network printer in your slicer using the external IP/hostname. Bambuddy receives your print, authenticates with your local printer, and relays everything securely.

  • No Port Forwarding Required

    Bambuddy transparently proxies traffic between your slicer and printer. Your printer stays safely on your local network.

  • Works Without VPN

    Connect from anywhere with internet access. A VPN like Tailscale adds full data encryption.

  • Tailscale-Aware UI

    Run Tailscale on the host. Bambuddy reads the host's tailnet identity and surfaces it on each virtual-printer card with a copy button — paste the 100.x.x.x into Bambu Studio or OrcaSlicer from anywhere on your tailnet. Private mesh, encrypted, no port forwarding. Per-VP toggle on the card controls whether the IP is shown. Setup guide →

  • No Bambu Cloud

    Full remote printing without relying on Bambu Lab's cloud infrastructure.

  • True End-to-End TLS

    FTP, FileTransfer, and Camera use transparent TCP proxying with your printer's real TLS certificate. MQTT is TLS-terminated only to rewrite network addresses.

  • Works with Bambu Studio & OrcaSlicer

    Add Bambuddy as a network printer and send prints directly from your slicer.

  • Real Printer Credentials

    Uses your actual printer's serial number and access code for authentication.

Integrated Slicing

Click Slice. Print. Slice STL and 3MF files server-side — no desktop slicer install needed. The optional sidecar runs OrcaSlicer or Bambu Studio headlessly inside Docker, and one Slice button in File Manager, Archives, MakerWorld, and the print queue produces a ready-to-print .gcode.3mf that drops into the existing dispatch flow.

How it works: Bring up the optional slicer-api/ Compose stack with docker compose up -d. In Bambuddy, go to Settings → Workflow → Slicer, toggle Use Slicer API on, and paste the sidecar URL. The Slice button now appears on file cards. Click it — the modal closes immediately and a toast tracker follows the job until the sliced .gcode.3mf lands in the library, ready for the plate picker, AMS mapper, and dispatch.

  • One-click Slice button everywhere

    Slice from File Manager, Archives, MakerWorld imports, and the print queue. Result lands in the library with embedded thumbnail, ready for the plate picker, AMS mapper, and dispatch.

  • Bambu Studio Preset Bundles (.bbscfg)

    Import a Printer Preset Bundle once, then pick its curated printer + process + filament triplet from a bundle dropdown for every slice. Repeat slicing skips the JSON profile re-upload entirely.

  • Slicer Pipelines — save a recipe once, apply it in one click

    Capture the Slice modal's printer + process + filament + bed-type combination as a named, reusable pipeline. Apply it to any file from File Manager, Archives, or MakerWorld with one click — no re-picking the triplet. Pipelines can target a specific printer or a printer class (any X1C / any H2D), slice once and dispatch up to N copies, and fan copies out across the matching printers in parallel (spread / single-printer / first-N strategies). Live runs dashboard on the Print Queue's Pipelines tab tracks every run with colour-coded status badges, per-copy detail on expand, cancel + retry-failed buttons on in-flight runs, and a clear-log control that only deletes terminal runs.

  • Per-AMS-slot filament dropdowns

    Multi-color plates render one filament dropdown per AMS slot the print actually uses, each labelled Filament N (PLA) with a colour swatch and auto-matched against your imported / cloud / standard presets by type and colour.

  • Multi-plate plate picker

    Multi-plate 3MFs open a plate picker first; the filament list and dropdown shape adapt to the picked plate's actual usage. Per-plate filament discovery is cached so opening the modal a second time on the same plate is instant.

  • Re-slice for any printer — including across nozzle classes

    A 3MF authored for one printer model can be re-sliced for another — pick the target in the Slice modal and the slicer regenerates G-code for its bed, kinematics, and nozzle count. Cross-class re-slices (single-nozzle X1C / P1S / A1 / P2S onto a dual-nozzle H2D / H2D Pro and vice versa) just work too: Bambuddy detects the class change and auto-arranges objects so they land safely on the target's bed and clear the H2D's per-nozzle dead zones. MakerWorld imports authored for any printer slice cleanly on yours.

  • Slice all plates at once

    Multi-plate projects — parted statues, multi-part kits, calibration test stacks — get a “Slice all N plates” toggle in the Slice modal. One click produces a single .gcode.3mf with every plate's G-code inside, ready to send to the printer. The toast shows “Plate 2 of 5 — Generating G-code (47%)” as it works through them, and Bambuddy handles the per-plate-then-merge dance for cross-class slice-all transparently.

  • Background jobs with toast tracker

    Long slices don't pin the modal — the job tracker follows the slice from queued to completed across pages. Library / archives lists refresh automatically when the result lands.

  • Headless-friendly

    Runs on a NAS, mini-PC, or RPi 5 without a desktop slicer install. Sidecar is a self-contained Docker Compose stack — docker compose up -d and the Slice button appears in Bambuddy.

  • OrcaSlicer or Bambu Studio

    Pick your preferred slicer in Settings → Workflow. Both ship as drop-in services with the same API surface, so you can switch any time.

  • Stays opt-in

    If you don't run the sidecar, all "Open in Slicer" flows continue to use the existing URI-scheme handoff to your desktop slicer, unchanged. Turning it on adds the Slice button without taking anything away.

Print Management

Comprehensive tools for organizing, archiving, and managing your 3D print files.

  • Automatic 3MF Archiving

    Files are automatically saved with full metadata preservation for future reference. Internal calibration prints are automatically filtered out.

  • Duplicate Detection

    Smart detection prevents redundant files from cluttering your archive.

  • Photo Attachments

    Document print results, failures, and notes with photo attachments.

  • Fusion 360 Design Files

    Attach F3D design files to archives for complete design tracking. Visual badge and one-click download.

  • External Links

    Link archives to Printables, Thingiverse, or any source URL. Globe button opens your custom link or auto-detected MakerWorld URL.

  • Print with AMS Mapping & Print Options

    Send any archived print to any printer from the unified Print dialog. For multi-plate 3MF files, select which plate to print with thumbnail previews. Auto-matches filaments by type and color, or manually select AMS slots from dropdown. On dual-nozzle printers (H2D/H2D Pro), filament matching is nozzle-aware — only AMS trays connected to the correct nozzle (L/R) are considered. Color names decoded from Bambu filament codes. Re-read button refreshes AMS status. Configure print options (bed leveling, flow calibration, vibration calibration, first layer inspection, timelapse) before dispatch.

  • Unified Print Button & Queue-Backed Dispatch

    Print button on archive cards opens the shared Print dialog for ASAP, Queue, or Schedule dispatch. Every print Bambuddy starts now flows through the queue scheduler — File Manager prints, archive reprints, printer-card upload-and-print, and scheduled queue items all share the same code path, so each print is visible on the queue page, attributable to the user that started it, deficit-checked, and cancellable from one place. No more "stealth prints" that bypass the queue.

  • Multi-Plate Browsing

    Browse plate thumbnails directly on archive cards. Hover to reveal navigation arrows and dots for cycling through plates in multi-plate 3MF files.

  • Embedded GCode Viewer

    3D-preview any archived print directly in Bambuddy — click the 3D-preview badge on an archive card to open the full-layer viewer. Multi-plate archives surface a plate picker with thumbnails; bed size auto-matches the printer the file was sliced for (H2D, X1C, P1S, A1, etc.) without any configuration.

  • Metadata Preservation

    Print settings, materials, and slicer configurations are stored with each file.

  • Per-archive Print Log

    Each archive tracks every individual print of that file. An orange N prints badge appears on the card whenever a model has been printed more than once; click it for the full run-by-run history with date, status, duration, filament used, cost, and failure reason. Reprints add new rows instead of overwriting the source archive's data — a 100 g successful print stays visible alongside a 10 g failed reprint, and Quick Stats correctly sum to 110 g across both events.

  • Global Print Log

    Chronological table view of all print activity across every printer. Search and filter by printer, user, status, or date range. Colored status badges show completed, failed, stopped, cancelled, and skipped prints at a glance. Includes duration and filament info. Log data is separate from archives — clearing the log never deletes your archived files.

  • Bambu Cloud Sync

    Optional integration with Bambu Cloud profiles for seamless workflow.

A red "Problem" counter in the status bar highlights printers with active HMS errors. Compact-mode status pips turn red for fatal/serious errors or amber for warnings.     View all your printers at a glance with unified status display.

  • H2 Series Nozzle Details

    Hover over nozzle cards for extended details — wear, serial number, max temp, and filament info. H2C shows a 6-slot nozzle rack card. Dual-nozzle printers show L/R details side by side with Active/Idle status.

    Adjust card sizes (S/M/L/XL) from the toolbar to fit your screen and preference.

    Put a printer "out of service" without removing it. The card stays visible on the dashboard with an amber wrench banner and an Exit button, so the printer never disappears from your mental map. Useful for parallel Bambuddy installs sharing the same hardware, printers under repair or awaiting parts, and temporary suspension.

Automation & Scheduling

Streamline your workflow with intelligent queue management and smart home integration.

  • Background Print Dispatch

    FTP uploads and print-start commands run in the background. Real-time progress toasts with per-job upload bars, status badges, and cancel support. UI responds immediately.

  • Tabbed Queue with Multi-Drag and Gantt Timeline

    Three tabs in one page: Queue for the live order (flat list or per-printer cards with aggregate count / time / weight), History for a responsive grid of past prints with filament swatch, weight, type, user, inline failure reason, and hover-to-enlarge thumbnails, and Timeline as a true Gantt swimlane — one row per printer with bars positioned by start time and sized by duration, a live NOW marker, and a rolling 24-hour window. Drag-and-drop supports multi-select: pick N items and the whole block moves together with a +N ghost.

  • Multi-Printer Selection

    Send prints to multiple printers at once with per-printer AMS mapping. Configure filament slots individually for each printer. Supports staggered starts directly from the Print dialog to avoid power spikes.

  • Model-Based Queue Assignment

    Queue prints to "any printer of matching model" (e.g., any X1C) for automatic load balancing. Optionally filter by location (e.g., "any X1C in Workshop"). Scheduler assigns to the first idle printer with the required filament types loaded. Override the sliced filament colors before scheduling — the scheduler matches against your chosen colors and prefers printers with exact matches.

  • Prefer Lowest Remaining Filament

    When multiple AMS spools match the same type and color, automatically select the one with the least filament remaining. Helps consume partial spools before starting new ones. Optional setting — disabled by default.

  • Time-Based Scheduling

    Schedule prints with a "do not start before" time, like overnight or off-peak hours. If the printer is busy at the scheduled time, the job stays queued until it can be dispatched.

  • Queue Mode

    Append prints to the back of the queue, or require manual start when you want to stage batches and release them yourself.

  • Bulk Queue Editing

    Select multiple queue items and edit printer assignment, print options, or cancel them all at once.

  • Select Plates to Queue

    Select any subset of plates from a multi-plate 3MF to queue at once. Each plate has a checkbox for multi-select, with a "Select All / Deselect All" toggle. Each selected plate is added as a separate queue entry, individually editable before dispatch.

  • Staggered Batch Start

    Stagger multi-printer starts to avoid power spikes. Available in both the Print dialog and the Queue dialog — prints sent to multiple printers are automatically queued with staggered start times. Define group size and interval — printers start in waves instead of all at once. Ideal for larger farms where simultaneous bed heating can trip breakers.

  • Batch Print Quantity

    Set a quantity in the Print dialog to create multiple queue items at once. ASAP batches are inserted at the top of the queue, while Queue batches append to the back unless manual start is required. Items are grouped into a batch for easy tracking.

    Batch Grouping

    Multi-plate prints from one source 3MF auto-group into a single collapsible row with aggregate count, total time, and total filament weight. Any 2+ selected items can be grouped manually via "Group as batch"; ungroup lives on the batch parent. History batches collapse into one row with status-rollup chips (e.g. 3 OK / 1 failed). Per-batch collapse state persists across reloads.

  • Smart Plug Integration

    Control printer power with Tasmota, Home Assistant, MQTT, or REST/Webhook smart plugs.

  • Auto Power-On

    Automatically turn on printers before scheduled print jobs.

  • Post-Cooldown Shutdown

    Safely power off printers after prints complete and cool down.

  • Clear Plate Confirmation

    Require user confirmation between queued prints to ensure the build plate is cleared before the next print starts. Disable per-printer confirmations in Settings for unattended farm workflows where plates are cleared automatically.

  • Shortest Job First (SJF)

    Prioritize shorter prints so more jobs complete sooner. Toggle SJF on the queue page — the scheduler picks the shortest pending job for each printer instead of FIFO. A starvation guard ensures long jobs that get skipped once are protected from being skipped again.

  • Configurable Default Print Options

    Set default values for bed levelling, flow calibration, vibration calibration, first layer inspection, and timelapse in Settings → Workflow. Every new print dialog starts with your chosen defaults, still overridable per print.

  • Auto-Print G-code Injection

    Configure custom start and end G-code snippets per printer model in Settings → Workflow for bed-clearing systems like Farmloop, SwapMod, AutoClear, and Printflow 3D. Enable per queue item — the scheduler injects snippets into a temporary copy of the 3MF before uploading, leaving original files untouched.

  • Preheat & Heat Soak

    Heat the bed (and the chamber, on supported printers) and hold at temperature before each queued print starts — the heat-soak engineering filaments need for adhesion and warp control. Bambuddy waits between FTP upload and print start, so the soak runs while the printer is otherwise idle. Per-print Inherit / On / Off override in the Print Options panel; per-filament chamber-target map under Settings → Workflow so PA wants 50°C, ABS 45°C, PETG-CF 40°C, and PLA derives 0°C and skips the chamber phase automatically. Hardware-aware: H-series / X2D / X1E actively heat the chamber via M141; X1C / P2S use bed radiation with a chamber-sensor wait; P1S / P1P / A1 fall back to a soak timer. On H-series / X2D / P2S the cooling/heating airduct flap auto-switches to match the resolved chamber target — ABS prints get the closed-flap recirculation they need, PLA prints get the open exhaust they need. M191 (wait-for-chamber-temp) isn't honoured by Bambu firmware, so doing this at the orchestration layer is the only place it works.

  • Maintenance Reminders

    Set up interval-based maintenance schedules for each printer.

Additional Capabilities

More features to enhance your 3D printing experience.

  • MakerWorld Integration

    Paste any MakerWorld model URL and save or slice the 3MF without leaving Bambuddy. Per-plate picker with Save or Save & Slice in Bambu Studio / OrcaSlicer, Import all plates for multi-plate models, folder picker, image gallery with keyboard-navigable lightbox, Recent imports sidebar, and per-plate delete with confirm modal. Reuses your existing Bambu Cloud login — no separate account, no companion browser extension, no cookie paste. MakerWorld HTML descriptions are sanitised via DOMPurify and CDN images are proxied through Bambuddy so your IP stays private. Closes the last workflow gap for LAN-only users who kept the Bambu Handy app around just for MakerWorld downloads.

  • Library Trash Bin & Admin Bulk Purge

    Deleted library files move to a trash bin with a configurable retention window (default 30 days) before a background sweeper permanently removes them — an undo window for accidental deletions. Regular users see and manage their own trashed files; admins see everyone's, can restore or delete permanently, and tune retention inline on the Trash page. For libraries that have grown into gigabytes, admins also get a Purge old bulk action with a live preview (count + total size freed + sample filenames) that moves every file older than N days into the trash in one shot, with an opt-in checkbox for never-printed files. Optional Auto-purge in Settings runs the same operation automatically once per 24 hours on an opt-in schedule, so admins never have to remember to clean up. Gated by a new library:purge permission (admin-only by default, delegable to other roles). External (linked) files bypass trash since their bytes aren't under Bambuddy's control.

  • Archive Auto-Purge

    Print archives can grow into tens of gigabytes over time — Settings → Archives now has an auto-purge toggle that hard-deletes archives older than a configurable age (default 365 days, minimum 7). A manual Purge archives now button opens a modal with a live preview (count + size) before you confirm. Unlike the library trash, archives are hard-deleted — print history is a decaying timeline, so there is no trash intermediate; the delete goes through the same safety-checked path as the single-archive delete button, cleaning up the 3MF, thumbnail, timelapse, source 3MF, F3D, and photo folder together with the DB row. Off by default; admin-only (reuses the existing archives:delete_all permission).

  • Spool Inventory

    Built-in spool tracking with AMS slot assignment, remaining weight editing, spool catalog, color catalog, and PA profile matching. Bulk spool addition (1–100 at once) with Quick Add mode for stock spools — material is required, brand and subtype are optional. Group similar spools toggle visually collapses identical unused/unassigned spools into expandable rows with a count badge. Automatic usage tracking via 3MF slicer data for all spools, with per-layer G-code accuracy for partial prints. Universal AMS mapping capture from any print source (BambuStudio, OrcaSlicer, Bambu Handy, or Bambuddy). AMS remain% delta as fallback. Mid-print spool reassignment support (uses live assignment if changed during print). Manual AMS weight sync for recovery from corrupted data. Per-spool cost tracking with automatic cost calculation at print completion, real-time cost preview in the print modal, and configurable default cost and currency. Multi-colour gradients, transparency, and visual effects — paste a comma-separated hex list (e.g. from 3dfilamentprofiles.com) to render a spool as a gradient strip or a colour-wheel pie (Multicolor subtype); alpha < FF shows through a checkerboard so transparency is visible; optional effect overlay (Sparkle, Wood, Marble, Glow, Matte). Same fields are editable on the colour catalog so combos can be saved once and reused.

  • Printable Spool Labels

    Generate PDF labels for any selection of spools in four pre-built sizes: AMS holder (30×15 mm) for the popular Makerworld AMS Filament Label Holder, single box label (62×29 mm) for Brother PT/QL or Dymo small labels, Avery L7160 sheets (A4, 21 per page), and Avery 5160 sheets (US Letter, 30 per page). AMS & Humidity Monitoring

Keep track of your Automatic Material System status and filament conditions.

  • Real-Time Humidity

    Monitor humidity levels inside each AMS unit to protect hygroscopic filaments.

  • Temperature Tracking

    View temperature readings from AMS-HT units for heated drying.

  • Remote AMS Drying

    Start, monitor, and stop drying sessions for AMS 2 Pro and AMS-HT directly from the Printers page. Select filament type for automatic temperature/duration presets, or set manually. Optional spool rotation for even heat distribution — the toggle is disabled per-AMS when any tray has filament threaded into the feed tube (the AMS mechanism is locked there; rotating would jam the filament). Real-time countdown shows drying progress. Requires supported printer firmware and external PSU. Bambuddy automatically detects power constraints from firmware — the drying button is disabled with a tooltip when no PSU is connected. AMS power-related HMS errors (fan failures, voltage issues) are shown in the HMS error panel.

  • Queue Auto-Drying

    Automatically dry AMS filament between scheduled prints. When a printer is idle and humidity exceeds the configured threshold, Bambuddy starts a drying session using the lowest safe temperature across loaded filaments. Each drying cycle runs for the configured duration and stops when it completes, when the next print is ready to start, or when auto-drying is disabled. Optional blocking mode waits for drying to complete before starting the next print.

  • Ambient Drying

    Keep filament dry on idle printers even without any queued prints. When enabled, Bambuddy monitors humidity and automatically starts a drying session whenever the threshold is exceeded, regardless of queue state. A separate toggle in Settings → Print Queue, independent from queue auto-drying.

  • Continue Drying While Printing

    On capable Bambu hardware (H2D 01.03.00.00+, H2C / H2S / P2S / H2D Pro 01.02.00.00+, X2D / A2L 01.01.00.00+, X1C 01.11.02.00+), auto-drying can keep running during a print — rather than stopping the moment a print starts. Off by default; opt-in toggle in Settings → Print Queue. The drying temperature is automatically capped 5°C below the idle preset (floor 40°C) to protect spools from the hot enclosure during a print, matching Bambu's own "lower drying temperature during printing" guidance. P1 series, A1, A1 Mini, X1 (non-C), and X1E are excluded — their firmware does not support concurrent drying during a print.

  • Configurable Drying Presets

    Customize drying temperature and duration for each filament type (PLA, PETG, TPU, ABS, ASA, PA, PC, PVA) with separate values for AMS 2 Pro and AMS-HT. Presets are used by manual drying, queue auto-drying, and ambient drying. Defaults based on BambuStudio's official filament profiles.

  • Per-Filament Humidity Threshold

    Set a different humidity trigger per filament type instead of one global value — e.g. Nylon at 20%, PLA at 60%, ASA at 30%. Mixed-material AMS units use the most-restrictive threshold across the loaded spools, so a single PLA + Nylon unit triggers at Nylon's level. Drives both the auto-drying scheduler and the hourly humidity alarm in lockstep. Configured in Settings → Workflow → Auto-Drying, alongside the drying presets.

  • Slot Status

    See which filament slots are loaded and their current states.

  • Load & Unload from the Printer Card

    Hover any AMS slot or external spool, click the menu button, and load that tray or unload the currently-loaded one — no walk to the touchscreen. On dual-extruder H2D, Ext-L and Ext-R drive their respective nozzles independently. Hidden while the printer is running. Requires the same control permission as start/stop/pause.

  • AMS Filament Backup Modal & Backup-Aware Deficit Check

    Mirrors BambuStudio's per-printer AMS Filament Backup setting — when a spool runs out, the printer auto-switches to a same-preset, same-colour spool in another slot so a long print can roll across multiple spools. A small badge in the Filaments section header on each printer card shows the live state (blue circular-arrow icon = ON, dim = OFF, "?" = A1 family with no cfg field); click to open a BambuStudio Auto Refill-style modal with one filament-coloured ring per backup pair — slot labels distributed around the colour band, material name and rotation count in the centre. Dual-extruder printers (H2D / H2C / X2D) carry an R / L badge per ring because the firmware can't cross extruders. Bambuddy's "insufficient filament" check is backup-aware: when Backup is ON, the deficit check pools remaining grams across same-(preset, colour) spools on the printer, so the warning doesn't fire spuriously when the firmware will swap to a peer mid-print. State syncs in real time whether the change came from Bambuddy, BambuStudio, or the printer's touchscreen. The companion Prefer Lowest Remaining Filament setting respects the backup toggle — when Backup is OFF, Bambuddy suppresses the prefer-lowest sort so the dispatcher won't reach for a near-empty spool the printer can't roll off of (#1762, #1766).

  • Configure AMS Slots

    Configure individual AMS slots with filament presets, colors, and K-profiles. Presets are filtered by printer model so only compatible filaments are shown. Re-configuring an already-configured slot pre-populates all fields (preset, color, K-profile) for quick edits.

  • Multi-AMS Support

    Monitor up to 4 AMS units per printer with unified display.

  • Nozzle-Aware Filament Mapping

    On dual-nozzle printers (H2D/H2D Pro), AMS filament matching respects nozzle assignments from the 3MF file. Each AMS unit feeds a specific nozzle (left or right), and Bambuddy constrains matching accordingly. L/R badges shown in the filament mapping UI.

  • Filament Track Switch (FTS) Support

    Bambuddy detects the Filament Track Switch accessory on dual-nozzle printers and adjusts the print modal accordingly. With the FTS installed the AMS is no longer wired to a fixed extruder — the FTS routes any slot to either nozzle on demand — so the per-nozzle filter is suppressed and every loaded slot is selectable. Slots currently fed into a track get an L/R badge so you can see at a glance where the FTS is routing them.

  • Dual External Spool Support

    Printers with multiple external spool holders (e.g., H2D with Ext-L and Ext-R) are fully supported. The external spool section renders as a grid layout accommodating multiple external slots instead of a single slot, with each slot independently configurable and trackable.

  • AMS Info Card & Custom Labels

    Hover over any AMS label to see its serial number and firmware version. Assign custom friendly names (e.g. "Silk Colours", "Workshop AMS") that persist even when the AMS is moved to a different printer. Slot numbers are displayed inside each filament color circle for quick identification.

Optional Authentication

Secure your Bambuddy instance with user authentication when needed.

  • Fully Optional

    Enable or disable authentication at any time. Existing installations work without authentication by default.

  • Group-Based Permissions

    80+ granular permissions with customizable groups and a full-page editor with search, bulk actions, and category-level toggles. Fine-grained inventory permissions let you control who sees spool assignments on printer cards vs. the full inventory page.

  • Ownership-Based Access

    Operators can only edit/delete their own archives, queue items, and library files. Administrators can modify any item.

  • User Management

    Create, edit, and delete users. Assign users to multiple groups for additive permissions.

  • JWT Authentication

    Secure token-based authentication with 7-day expiration. Passwords are securely hashed using PBKDF2.

  • User Activity Tracking

    Track who uploaded archives, library files, and who added print jobs to the queue. See usernames on archive cards, file cards, queue items, and while printing. Each user gets their own independent Bambu Cloud login for cloud profiles.

  • Advanced Auth via Email

    Configure SMTP for automated user onboarding. Admins create users with an email address and the system sends a secure random password automatically — no shared passwords.

  • Self-Service Password Reset

    Users can reset their own password from the login screen without contacting an admin. Admins can also trigger one-click password resets from user management.

  • LDAP / Active Directory

    Authenticate users against your existing LDAP or Active Directory server. Supports LDAPS and StartTLS encryption, auto-provisioning on first login (or manual provisioning via an admin-side directory search), and LDAP group-to-BamBuddy group mapping for automatic role assignment. Local admin accounts remain as fallback.

  • Two-Factor Authentication (TOTP + Email OTP)

    Per-user opt-in 2FA with TOTP (Google Authenticator, Authy, 2FAS, or any standard TOTP app) or a 6-digit code delivered by email. Each user gets 10 single-use backup codes, printable or savable in a password manager. Hardened against brute-force (per-user and per-IP rate limits), replay (a TOTP code cannot be accepted twice in the same 30-second window, including across setup, verify, disable, and backup-code regeneration), and token reuse (the pre-auth challenge is a single-use DB-backed token bound to the browser via an HttpOnly cookie).

  • Single Sign-On (OIDC / SSO)

    Log in to BamBuddy via any standards-compliant OIDC provider — PocketID, Authentik, Keycloak, Google Workspace, Azure AD — with PKCE (S256) for public clients. BamBuddy validates the issuer, aud, nonce, and email_verified claims on every callback, and the admin UI can opt-in to auto-provisioning of new BamBuddy users or auto-linking to existing accounts via their verified email address. Every URL pulled from the OIDC discovery document is validated against private/loopback/link-local IPs to prevent SSRF; non-HTTPS issuer URLs are rejected outright.

  • Email Templates

    Customizable notification templates for welcome emails and password resets. Advanced auth can be enabled or disabled independently at any time.

  • Per-User Email Notifications

    Individual users can receive email notifications for their own print jobs — start, complete, failed, and stopped events — with per-user toggle controls on a dedicated Notifications page.
